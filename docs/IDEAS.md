## CodeIsland (wxtsky/CodeIsland)
- **Link:** https://github.com/wxtsky/CodeIsland
- **License:** MIT (from its `LICENSE` file, read on 2026-10-02)
- **What we read:** the README and the LICENSE file. We did not read the source code.
- **What it is** (from its README, not tested by us): a notch app that shows the live status of AI coding agents
  and lets you approve tool calls and answer questions from the notch. It says it supports 30+ tools.
- **Use here:** personal use first (owner decision). The code is written from scratch.

| Idea | Where it went |
|---|---|
| Live status of coding agent sessions | F-20 (R2), Claude Code and Codex CLI only |
| Quiet rules: no alert when you look at that session, quiet hours, mute while locked | F-21 (Later) |
| Approve or deny a tool call from the notch | F-22 (Later, high risk) |
| Same status for the Codex desktop app | F-23 (Later) |
| Click a session to jump to its terminal tab | F-24 (Later) |
| Support for more tools | F-25 (Later, new provider only on demand) |

Not taken: push to phone or chat, webhooks, iPhone / Apple Watch / ESP32 companions, 30+ tools, mascots.
See "Not planned" in `docs/FEATURES.md`.

**Not verified by us:** every claim above comes from the README. For example, that Codex needs the user to trust a hook once,
how the hooks are installed, and the supported macOS versions. Spike S-006 checks what matters for us on the real Mac.

**Also noted:** the README credits another project, claude-island, as the original idea. We have not read it.
